# 二輪問診（daijoubu-check）

Built with Claude: Japan 2026（テーマ2「本来、誰にでも届くべきものを。」）の提出作品です。

まずジャイロキャノピー（屋根つきの3輪スクーター）乗りのための相談相手です。バイクの気になることを、普段の言葉で相談できます。

修理を頼める店が減っています。バイク屋の高齢化や閉店があり、日々の仕事で手が回らない店もあります。個人売買で素性の分からないバイクも増え、修理に手間がかかりますが、その手間の理由は乗る人に伝わりにくい。二輪問診は、その間で、乗る人が整備士の確かめた順番で自分で確かめ、確かめたことを「お店に見せる1枚」にまとめられるようにします。店は探しません。店が減ることも解決しません。

- 整備士本人が確かめたことだけで答えます。
- 確かめていないことには答えません。
- 話の確かさを分けて残します。
- 本人の一言で、次から答えられるようになります。

確かめたことは言い切ります。たとえば「プラグはスピードが出ないことには影響しません」です。ただし、相談者の車の原因は決めません。

## 動きの例

- **答える**：「スピードが出ない」と書くと、確かめることを1つずつ聞きます。必要なもの、これでは分からないこと、出所も画面に出します。
- **答えない**：記録のない相談には「まだ確かめていない話です。確かめていないことには答えません。」と返します。
- **分けて残す**：話を「自分で確かめたこと」「聞いた話」「推測」「まだ分からないこと」に分けます。「見たのは兄でした」と言い直すと、聞いた話へ移り、それを支えにしていた比較は外れます。元の言い方も履歴に残します。
- **本人の一言で増やす**：止まった相談に大谷が答えると、その言葉を `data/flows.json` に足します。次からはそれも根拠にします。プラグとスピードの関係、ベルトの交換距離（ジャイロは1万キロごと）は、この形で足しました。
- **外せない人に合わせる**：「自分では部品を外せない」と言うと、外す確認は頼みません。
- **お店に見せる**：買った所（個人売買も選べます）、最後の整備、確かめたこと、聞いた話、まだ分からないことを1枚の文にまとめて写せます。推測は入れません。

## 動かし方

Node.js 24 以降を使います。

```bash
npm install
node --env-file=private/.env src/server.mjs
```

`private/.env` に `ANTHROPIC_API_KEY` を書きます。`private/` は公開しません。本人確認前の記録を開発で見る時だけ `ALLOW_UNCHECKED=1` を足します。この時は画面に「開発中」と出ます。

確かめる時は次を使います。

```bash
node tools/check_cards.mjs
node --test
```

## 作りの要点

- `src/claude.mjs`、`src/prompt.mjs`：相談文を読み、話を分け、記録と結びつけ、返答を作ります。
- `src/engine.mjs`：訂正で支えを失った比較を、プログラムで外します。判断の連動はClaudeに任せません。
- `src/guard.mjs`：実在しない場面、本人確認前の記録、「大丈夫です」「原因は〜です」のような車についての言い切りを、返す前に止めます。
- `src/seal.mjs`：画面から戻る台帳に署名を付け、書き換えを防ぎます。
- `src/limits.mjs`：回数の上限と、台帳の形を確かめます。
- `data/cards.json`：大谷の動画から抜き出した場面と、本人の確認内容です。
- `data/flows.json`：症状ごとに確かめる順番です。
- `tools/compare.mjs`、`src/rag.mjs`：普通のRAGと、方式を隠して比べる道具です。

## 普通のRAGとの比較

2回行いました。どちらも正解はClaudeの下書き、採点は方式を知らないAI3人の多数決で、大谷の確認前の暫定です。比べたのは読み取りの部分だけで、画面の検査と点検の流れは通っていません。

| | 訂正 | 通常・該当なし |
|---|---|---|
| 1回目（本作 対 RAG） | 1対5 | 4対1 |
| 再試験（本作 対 RAG） | 3対2 | 2対1 |

再試験は5問だけで、差は1問です。優劣は言えません。問題は `data/eval/` にあります。大谷が先に正解を決める2回目は、まだ行っていません。

## まだできていないこと

- 確認済みの記録は一部です。止まる相談はまだ多くあります。
- 止まった相談は、動いているサーバーの `private/questions.jsonl` に残ります。`QUESTION_URL` と `QUESTION_TOKEN` を設定すると外の保存先へも送りますが、受け側はまだ公開していません。公開版では設定していないので、止まった相談は大谷に届かず、再起動で消えます。一言を足す作業は手で行います。
- 点検の流れの本文は日本語だけです。英語の画面では、Claudeが訳した文を出します。
- 店を探す機能はありません。「お店に見せる1枚」を実際の店で使った例はまだありません。
