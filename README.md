# 二輪問診（daijoubu-check）

Built with Claude: Japan 2026（テーマ1「あなたにしかない深さを」）の提出作品です。

まずジャイロキャノピー（屋根つきの3輪スクーター）乗りのための相談相手です。バイクの気になることを、普段の言葉で相談できます。

修理を頼める店が減っています。バイク屋の高齢化や閉店があり、日々の仕事で手が回らない店もあります。個人売買で素性の分からないバイクも増え、修理に手間がかかりますが、その手間の理由は乗る人に伝わりにくい。二輪問診は、その間で、乗る人が整備士の確かめた順番で自分で確かめ、確かめたことを「お店に見せる1枚」にまとめられるようにします。店は探しません。店が減ることも解決しません。

- 整備士本人が確かめたことだけで答えます。
- 確かめていないことには答えません。
- 話の確かさを分けて残します。
- 本人の一言で、次から答えられるようになります。

確かめたことは言い切ります。たとえば「プラグはスピードが出ないことには影響しません」です。ただし、相談者の車の原因は決めません。

## 動きの例

- **答える**：「スピードが出ない」と書くと、確かめることを1つずつ聞きます。必要なもの、これでは分からないこと、出所も画面に出します。
- **答えない**：記録のない相談には「まだ確かめていない話です。確かめていないことには答えません。」と返します。
- **分けて残す**：話を「自分で確かめたこと」「聞いた話」「推測」「まだ分からないこと」に分けます。「見たのは兄でした」と言い直すと、聞いた話へ移り、それを支えにしていた比較は外れます。元の言い方も履歴に残します。
- **本人の一言で増やす**：止まった相談は、その場で大谷の非公開リポジトリに Issue として届きます（相談の文と時刻だけ）。大谷が答えると、その言葉を `data/flows.json` に足します。次からはそれも根拠にします。プラグとスピードの関係、ベルトの交換距離（ジャイロは1万キロごと）は、この形で足しました。
- **値段を聞かれたら**：金額はClaudeに言わせません（返す前の検査で止めます）。代わりに、大谷の店（WINGオオタニ）が wing-canopy.com で公開している修理料金（`data/prices.json`、2026-11-06 時点）から、相談に関係するものを3つまで「参考価格」として添えます。実際の値段は車を見てからの見積もりで決まる、と一緒に出します。記録に無い症状に値段が添えられた相談は、止めたまま参考価格を添え、止まった相談として大谷に届きます。
- **外せない人に合わせる**：「自分では部品を外せない」と言うと、外す確認は頼みません。
- **中で起きたことを見せる**：返事のたびに、その下に1行で出します。例「Claude 1回・13.9秒 ／ 発言を1つ分けた（確かめた1） ／ 記録1件・流れ「スピードが出ない、発進が遅い」の確認1/10 ／ 返す前の検査 通過」。言い直した時は「1つを言い直しで移した ／ 外した比較1件」、検査で止めてやり直した時はその理由（言い切り・金額など）が出ます。Claudeの文ではなく、プログラムが数えた事実です（`src/trace.mjs`）。
- **お店に見せる**：買った所（個人売買も選べます）、最後の整備、確かめたこと、聞いた話、まだ分からないことを1枚の文にまとめて写せます。推測は入れません。

## 動かし方

Node.js 24 以降を使います。

```bash
npm install
node --env-file=private/.env src/server.mjs
```

`private/.env` に `ANTHROPIC_API_KEY` を書きます。`private/` は公開しません。本人確認前の記録を開発で見る時だけ `ALLOW_UNCHECKED=1` を足します。この時は画面に「開発中」と出ます。

確かめる時は次を使います。

```bash
node tools/check_cards.mjs
node --test
```

## 仕組み（1回の相談で中で起きること）

```
相談の文（画面）
  │  台帳（これまでの発言）に署名を付けて往復。サーバーは保存しない（src/seal.mjs）
  ▼
Claude ─ 記録カードと点検の流れだけを根拠に、JSONで返す（src/claude.mjs, src/prompt.mjs）
  │     発言を「確かめた／聞いた／推測／分からない」に分ける・使う記録・次に確かめること
  ▼
プログラム ─ 台帳に反映。言い直しで支えを失った比較を外す（src/engine.mjs）。判断の連動はClaudeに任せない
  ▼
検査 ─ 実在しない記録・本人確認前の記録・「大丈夫です」「原因は〜」の言い切り・金額・根拠なしを、返す前に止める（src/guard.mjs）
  │     落ちたら理由を添えて1回だけやり直し。それでも駄目なら、流れの問いだけ返すか止める
  ▼
画面 ─ 返事・札・出所の場面・参考価格（data/prices.json）・「中で起きたこと」の1行（src/trace.mjs）
        止まった相談は Issue で大谷に届く → 本人の一言を data/flows.json に足す → 次から答えられる
```

## 作りの要点

- `src/claude.mjs`、`src/prompt.mjs`：相談文を読み、話を分け、記録と結びつけ、返答を作ります。
- `src/engine.mjs`：訂正で支えを失った比較を、プログラムで外します。判断の連動はClaudeに任せません。
- `src/guard.mjs`：実在しない場面、本人確認前の記録、「大丈夫です」「原因は〜です」のような車についての言い切りを、返す前に止めます。
- `src/seal.mjs`：画面から戻る台帳に署名を付け、書き換えを防ぎます。
- `src/limits.mjs`：回数の上限と、台帳の形を確かめます。
- `src/trace.mjs`：1回の相談で中で起きたこと（Claudeを呼んだ回数・分けた発言・使った記録・検査の結果・外した比較・秒）を数え、画面に1行で出します。
- `data/cards.json`：大谷の動画から抜き出した場面と、本人の確認内容です。
- `data/flows.json`：症状ごとに確かめる順番です。
- `data/prices.json`、`src/prices.mjs`：大谷の店の公開料金と、値段の質問にそれを添える仕組みです。
- `tools/compare.mjs`、`src/rag.mjs`：普通のRAGと、方式を隠して比べる道具です。

## 普通のRAGとの比較

2回行いました。どちらも正解はClaudeの下書き、採点は方式を知らないAI3人の多数決で、大谷の確認前の暫定です。比べたのは読み取りの部分だけで、画面の検査と点検の流れは通っていません。

| | 訂正 | 通常・該当なし |
|---|---|---|
| 1回目（本作 対 RAG） | 1対5 | 4対1 |
| 再試験（本作 対 RAG） | 3対2 | 2対1 |

再試験は5問だけで、差は1問です。優劣は言えません。問題は `data/eval/` にあります。大谷が先に正解を決める2回目は、まだ行っていません。

## まだできていないこと

- 確認済みの記録は一部です。止まる相談はまだ多くあります。
- 止まった相談は、動いているサーバーの `private/questions.jsonl` に残るほか、`QUESTION_URL` と `QUESTION_TOKEN` に大谷の非公開リポジトリ（daijoubu-inbox）の issues と、そのリポジトリの Issues 書き込みだけのトークンを設定してあるので、その場で Issue として届きます（相談の文と時刻だけ。文はそのまま送るので、名前や連絡先を書かないよう画面と止まった時の返事で伝えます）。Discord の webhook にも送れる作りですが、Discord は Render からの送信を長時間止めるため（retry_after 約22時間を実測）使っていません。届いた相談に大谷が答える作業と、その言葉を点検の流れに足す作業は、Claude Code で手で行います（2026-11-06 に追加・公開版で確認）。
- 点検の流れの本文は日本語だけです。英語の画面では、Claudeが訳した文を出します。
- 店を探す機能はありません。「お店に見せる1枚」を実際の店で使った例はまだありません。
