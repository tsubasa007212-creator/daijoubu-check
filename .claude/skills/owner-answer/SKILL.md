# 大谷の回答を流れにする

1. 大谷の言葉をそのまま `private/大谷さんの確認メモ.md` に書く。言い換えない。
2. `data/flows.json` の該当の流れに足す。なければ新しい流れを作る。
3. 足す step は `source` を `owner` にし、`how` は大谷の言葉から離れない。一般知識や推測を補わない。
4. 大谷が言っていないことは `cannot_tell` に「まだ確かめていない」と書く。
5. `scope` は大谷が言った範囲にする。言っていない車種へ広げない。
6. `node tools/check_cards.mjs` と `npm test` を通す。
7. 公開版の設定で、止まっていた相談をもう一度入れて、答えが変わることを確かめる。

動画ができたら `video_id`、`t`、`line` を足し、`source` を `video` にする。
