# 作りの地図

主語は次の4つです。

- 整備士本人が確かめたことだけで答える
- 確かめていないことには答えない
- 話の確かさを分けて残す
- 本人の一言で次から答えられる

## 1回の相談の流れ

```
画面 (public/)  台帳と署名を持ち、発言と一緒に送る
  ↓
サーバー (src/server.mjs)  発言の長さ、台帳の形、署名、回数を確かめる
  ↓
Claude (src/claude.mjs, src/prompt.mjs)  話を分け、記録と結ぶ。次の確認と返答を作る
  ↓
仕組み (src/engine.mjs)  台帳へ反映し、訂正で外れる比較を計算する
  ↓
検査 (src/guard.mjs)  根拠の外と、車についての言い切りを止める
  ↓
通れば返す。落ちたら理由を添えて1回だけやり直す
```

やり直しても落ちた時は、次のどちらかです。

- 言い切りだけが問題で、流れの確認を聞いている時：流れの問いをそのまま聞く。
- それ以外：「まだ確かめていない話です。確かめていないことには答えません。」と返す。

止まっても、相談者の発言は台帳に残します。

## 根拠にできるもの

| もの | 場所 | 今の数（確認済み／全部） |
|---|---|---|
| 記録カード | `data/cards.json` | 5枚／27枚 |
| 点検の流れ | `data/flows.json` | 6本／10本 |
| 流れの中の確認 | `data/flows.json` | 26個／44個 |

- 数は2026-11-03の実測です。
- サーバーは `human_check` が `approved` のものだけをClaudeと画面へ渡します。
- 検査でも同じことを確かめます。
- `ALLOW_UNCHECKED=1` の時だけ、確認前のものも出ます。開発専用です。
- 確認の出所は `source` に書きます。`owner` は大谷の話、`video` は動画です。

## 話の分け方

| 分け方 | 意味 |
|---|---|
| `checked` | 相談者本人が見た、聞いた、触ったこと |
| `heard` | 他の人から聞いた話 |
| `guess` | 確かめていない判断 |
| `unknown` | 確かめられていないと分かったこと |

- 発言は消さず、出所と文だけを変えます。元の言い方は履歴に残します。
- 訂正で本人の確認でなくなった発言の比較は外れます。文が直った発言の比較も外れます。
- 文が直った発言は、結び直せば比較が戻ります。
- 最初から聞いた話の比較は、聞いた話のまま残ります。
- 台帳はサーバーに保存しません。画面が持ち、署名で書き換えを防ぎます。

## 言い切りの線引き

確かめたことは言い切ります。流れの内容は「大谷は〜」と付けず、自分たちの言葉で言います。

車の原因は決めません。「大丈夫です」「壊れています」「原因は〜です」「交換してください」のような文は `src/guard.mjs` が止めます。店へ行くよう勧める文も止めます。行動は、流れの `how` や `stop_here` にある時だけ伝えます。

動画の記録を引く時は「別の車の記録」と言います。

## 本人の一言を足す手順

手順は `.claude/skills/owner-answer/SKILL.md` にあります。

1. 大谷の言葉をそのまま確認メモに書く。
2. `data/flows.json` に足す。`source` は `owner`、`scope` は本人が言った範囲だけにする。
3. 言っていないことは足さず、`cannot_tell` に書く。
4. `node tools/check_cards.mjs` と `node --test` を通す。
5. 公開の設定で、止まっていた相談を入れ直す。

止まった相談は、サーバーの `private/questions.jsonl` に残ります。公開先によっては再起動で消えます。`QUESTION_URL` と `QUESTION_TOKEN` を設定すると https で外の保存先へも送ります。失敗しても返答は止めず、再送はしません。

## 直す場所

| やりたいこと | 直す場所 |
|---|---|
| 記録を増やす | `data/cards.json`。手順は `.claude/skills/card-from-video/` |
| 本人の話を足す | `data/flows.json`。手順は上のとおり |
| 言語を増やす | `public/i18n.js` に1言語足す。`src/config.mjs` の `STOP_REPLY`、`src/guard.mjs` の言い切りの文も足す |
| 車種を増やす | カードか流れを足す。流れの `scope` は本人が言った範囲だけにする |
| モデルや上限を変える | `src/config.mjs`（環境変数でも変えられる） |
| Claudeへの指示を変える | `src/prompt.mjs`。変えたら比較をやり直す |

## その他の道具

ここに書くのは、置いてある物の役目です。使った記録があるとは限りません。

| 道具 | 役目 |
|---|---|
| `tools/check_cards.mjs` | カードと流れの形を確かめる。作業用の字幕があれば時刻も確かめる。CIの手順に入っている |
| `tools/compare.mjs`, `src/rag.mjs` | 普通のRAGとの比較。カードと読み取りだけで、流れと検査は通らない |
| `tools/try_turns.mjs` | 画面なしの試し。確認前のカードも通し、流れは渡さない |
| `tools/hooks/before_commit.mjs` | commit の前に鍵と非公開ファイルを止める設定 |
| `tools/mcp/records.mjs` | 記録と匿名化済みの質問を読むだけのMCP。匿名化済みの一覧は今はない |
| `.claude/agents/card-reviewer.md` | カードと字幕を照合する役の設定。読むだけで書き換えない |

## 守ること

- 判断の連動はプログラムで行い、Claudeに任せない。
- `human_check` が `approved` の記録だけを公開する。
- `private/` は公開しない。メーカーの資料を入れない。
- 比較の結果から、普通のRAGとの優劣は言わない。
